# 🚀 Tech Challenger - Grupo 13 (FIAP)

Backend desenvolvido com **Java 21** e **Spring Boot 3.5.5** para gerenciamento de usuários, restaurantes e cardapios, pronto para rodar com **Docker Compose**.

---

## 🛠️ Tecnologias Utilizadas

- ☕ Java 21  
- 🌱 Spring Boot 3.5.5  
- 🗃️ Spring Data JPA  
- 🐬 MySQL  
- 🧰 Maven Wrapper  
- 🐳 Docker & Docker Compose  

---

## 📦 Passo a Passo

### 1️⃣ Subir com Docker Compose
docker-compose up

A aplicação estará disponível em:
🔗 http://localhost:8080
